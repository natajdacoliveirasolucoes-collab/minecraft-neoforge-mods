# PackRules 1.0.5

Bloqueio configuravel de entidades e demonstracao administrativa de campeoes na barra de acao.

Minecraft 1.21.1 / NeoForge 21.1.265 / Java 21.

Lado: Servidor.

Projeto proprio.

Artefato: `PackRules-1.0.5.jar`.

Build: entre neste diretorio e execute `./gradlew build --console=plain` (Windows: `gradlew.bat build --console=plain`).

Agora inclui ajustes de precificacao ProjectE e amostras administrativas de saldo em texto. Os registros ficam no servidor e nao sao enviados aos jogadores. As regras sao configuraveis; os fontes publicados nao incluem configuracoes de operadores.
