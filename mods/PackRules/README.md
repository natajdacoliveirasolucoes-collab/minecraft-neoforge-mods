# PackRules 1.0.1

Bloqueio configuravel de entidades e demonstracao administrativa de campeoes na barra de acao.

Minecraft 1.21.1 / NeoForge 21.1.265 / Java 21.

Lado: Servidor.

Projeto proprio.

Artefato: `PackRules-1.0.1.jar`.

Build: entre neste diretorio e execute `./gradlew build --console=plain` (Windows: `gradlew.bat build --console=plain`).
