# ServerCountdown 1.0.1

Bossbar de contagem; comandos ao vivo; preferencias individuais; horario America/Manaus.

Minecraft 1.21.1 / NeoForge 21.1.265 / Java 21.

Lado: Servidor.

Projeto proprio.

Artefato: `ServerCountdown-1.0.1.jar`.

Build: entre neste diretorio e execute `./gradlew build --console=plain` (Windows: `gradlew.bat build --console=plain`).

Console: `countdown definir AAAA-MM-DD HH:mm Titulo`, `countdown status`, `countdown parar`, `countdown recarregar`.
Jogador: `/countdown mostrar` e `/countdown ocultar`. Horarios usam America/Manaus (GMT-4).
