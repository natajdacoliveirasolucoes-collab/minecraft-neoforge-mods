# TrophyHeads 1.0.2

Captura independente da skin na coleta; integracao com Quick Skin; compatibilidade dos trofeus antigos.

Minecraft 1.21.1 / NeoForge 21.1.265 / Java 21.

Lado: Servidor; cliente para renderizar snapshots PNG.

Projeto proprio.

Artefato: `TrophyHeads-1.0.2.jar`.

Build: entre neste diretorio e execute `./gradlew build --console=plain` (Windows: `gradlew.bat build --console=plain`).

O ID persistente examplemod e as chaves antigas sao preservados. Instale no cliente para snapshots PNG com Quick Skin.
Trofeus anteriores preservam as propriedades existentes; uma textura historica nunca capturada nao pode ser reconstruida.
